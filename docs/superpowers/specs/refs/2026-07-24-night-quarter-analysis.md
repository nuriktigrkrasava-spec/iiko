# Разбор референса: ночной квартал (image-to-code)

Референс: `night-quarter-reference.png` (1254×1254, изометрический пиксель-арт).
Семплирование честное — PIL по зонам и кластерам ярких пикселей, не на глаз.

## Палитра (семплы)

**Поверхности** — тёплый почти-чёрный, не нейтральный. Кластеры тёмных
пикселей: `#080810`, `#181010`, `#201818` — в тенях лёгкий фиолетовый холод,
в камне фасадов — тёплый сдвиг. Пустота вокруг сцены — чистый `#000000`.

**Свет** — единственный источник жизни. Пик оконного света `#F1BA68`
(золотисто-янтарный), средний тон свечения `#995A2B`, фонарь `#B88D53`,
глубина тёплой комнаты `#3D2717`. Света на картинке много (20 тыс. пикселей
в кластере) — это доминирующий акцент.

**Красный = потеря.** Пик свечения красного здания `#EA4F10`, средний
`#8A2A12`, глубина `#561708`. Красный на картинке ровно один объект —
и его находишь мгновенно. В UI так же: одна семантика, один объект внимания.

**Зелёный почти отсутствует** (84 пикселя, олива `#415119` — растения).
В UI зелёный появляется только когда деньги вернулись.

## Характер света

Свет изнутри наружу: тёмная оболочка, тёплое ядро. Никаких бликов, глянца,
градиентов на поверхностях — свечение только там, где есть смысл («жизнь»
в окнах, потеря в красном здании). Перенос в UI: фон и карточки матовые,
свечение (glow/wash) допустимо только у суммы потери и у «жизни» сцены.

## Плотность и геометрия

Сцена плотная, но воздух создаёт чёрная пустота вокруг. Пиксель-арт делает
грани резкими, но UI-хром должен остаться телеграм-родным: мягкие радиусы
12–16, шторки 20 сверху. Пиксельная резкость живёт только внутри сцены
«Города», не в контролах.

## Типографика

В референсе шрифтов нет («никаких подписей на сцене»). Тип берём из уже
принятой системы сторис: Onest для текста, JetBrains Mono с tabular-nums
для денег. Пиксельных шрифтов не будет — игровых элементов быть не должно.

## Якорная система

Ближайшие из `aesthetic-systems`: luxury (тёмный монохром, премиум) +
elevenlabs/runwayml (dark cinematic). Рецепт: одна тёмная семья поверхностей,
один тёплый акцент (янтарный свет), хроматика только у денег.

Итог: токены в `web/src/miniapp/tokens.json`, тема в
`web/src/miniapp/theme.css`. Хром обычных вкладок — из `--tg-theme-*`
с фолбэками; сцена «Город» и «Отчёт» — всегда ночная, тема пользователя
игнорируется (как видеоплеер).
