## ТЕКУЩЕЕ СОСТОЯНИЕ (что уже построено, работает, TSC 0)
- **Директор (домашний экран, `lg/Director.tsx`)** — ШАГ 4: единая оценка `40/100` (кольцо-гейдж) + «из чего складывается» (разбор факторов, «нет данных» для Посадки/KDS/Соцсетей), мастер-полоска возврата, путь-станции, план результатов `сейчас→после=+₸` с приоритетом деньги÷усилие, усилием (быстро/средне/долго) и **шагами «как достичь»**.
- **Склад · строгий баланс** — в `lg/Supply.tsx` (внизу): было+приход−остаток=факт, расхождение в ₸ (leak-бары), остатки «≈ на складе», изоляция по филиалу. Бэкенд `/api/stock/{org}` в `api.py` (демо + TODO real по iiko-остаткам).
- **Отчёт недели (`lg/Report.tsx`)** — «что улучшилось за неделю» (недельные дельты) + «как идём по плану». Это тот же директор по расписанию.
- **Дизайн-система:** один класс `.glass` (frosted, тёмная+светлая), чёрный фон тёмной темы (`lg.css`), шрифт заголовков/дока **Unbounded** (подключён в `web/index.html`), правило **«цвет только на деньгах»** (красный=потеря, зелёный=возврат, остальное монохром), столбцы в отчёте монохромные плоские со скруглённым верхом (`charts.ts barChart`).
- **Мини-апп (Telegram, отдельный продукт)** — старый `index.html` в проде (deploy-cashshifts), туда встроено «Расписание» (вкладка Смены). НЕ путать с сайтом! См. память `prod-miniapp-is-old-index-html`.
